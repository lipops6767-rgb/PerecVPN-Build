# Как получить APK без ПК

1. Загрузите содержимое этого архива в корень GitHub-репозитория (не сам ZIP).
2. После Commit changes откройте вкладку Actions.
3. Выберите `Build PerecVPN APK`.
4. Нажмите последний запущенный workflow.
5. Внизу страницы скачайте artifact `PerecVPN-debug-apk`.
6. Внутри будет `app-debug.apk`.

Важно: это автоматическая сборка проекта. Перед публикацией или установкой на основной телефон APK нужно протестировать. Этот проект не является гарантированно протестированным VPN-клиентом.
